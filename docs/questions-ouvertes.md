# Questions ouvertes au joueur

Chaque question a un **numéro fixe**, qui ne change jamais, même quand d'autres questions sont posées ou résolues. On regroupe ou on renumérote seulement si le joueur le demande. Une question résolue est barrée et datée ; ses réponses vont dans `docs/game-design.md`. Les nouvelles questions prennent le numéro suivant.
