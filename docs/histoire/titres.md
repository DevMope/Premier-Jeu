# Des titres pour le jeu

Le cadre ★ : ni « Le Passage des Aventuriers », ni « Le Comptoir des Aventuriers ». Les titres sonnent mieux en anglais, et la décision reste ouverte.

Ce qu'un bon titre doit faire entendre :
- le comptoir qui équipe les héros ;
- l'oubli ;
- la vérité cachée ;
- les deux voies.

**La vérification** (29/10) : j'ai fait des recherches sur le web pour chaque titre marqué « vérifié » (Steam, itch.io, presse). Je n'y ai trouvé aucun jeu connu sous ce nom exact. Ce n'est pas une recherche de marque déposée : il faudra en faire une avant d'annoncer le titre.

**Les titres écartés** après vérification :
- *Ledger of Oblivion* : c'est un objet de *Disco Elysium* ;
- *Borrowed Light* : c'est un jeu sur Steam (un roguelite) ;
- *The Unremembered* : c'est un roman (Peter Orullian) ;
- *Remnant* et *Unwritten* : ce sont des jeux connus.

## Ma recommandation

**Counterlight** (*Contre-Lumière*).
- C'est un seul mot, court, qui se retient et qui ne ressemble à aucun jeu connu.
- Il dit le comptoir, le cœur du jeu, sans le mot « shop ».
- Il dit aussi le secret : la Lumière n'est pas ce qu'elle prétend, et l'on peut se dresser contre elle.
- Il garde les deux voies : la lumière est dans le mot, son contraire aussi.
- Son défaut : en français, « Contre-Lumière » perd le jeu de mots sur le comptoir. On pourrait garder le titre anglais partout, avec un sous-titre français (« Le comptoir des Ouvre-Routes »).

**En second choix** : *What the Lake Remembers*, si l'on veut un titre plus poétique, centré sur l'oubli et la berceuse, au risque d'effacer le comptoir. Ou *The Last Rampart*, plus épique, mais plus proche de titres existants.
