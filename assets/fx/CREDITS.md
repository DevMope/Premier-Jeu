# Essai d'assets téléchargés (v0.70, à valider)

Source : packs **Kenney** (CC0 1.0, domaine public, crédit facultatif) trouvés dans le dépôt
GitHub `Tiddybub/2d-assets` : *Particle Pack 1.1* (flammes, étincelles, traînées, cercles),
*Smoke Particles* (bouffées de fumée), *Splat Pack*.

Les particules d'origine sont lisses (en dégradé) ; `pixeliser.py` les ramène à notre grille de
pixels et à notre palette (feu, fumée, eau), avec un tramage 2×2, puis le jeu les anime comme des
particules (montée, étirement, fondu, gravité). Animation d'essai : `docs/planches-v059/9-essai-effets.gif`.

Crédit (facultatif mais mérité) : Kenney (www.kenney.nl).
